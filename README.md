# 夜当 · MVP 试玩

竖屏 HTML5 经营验货小游戏（vanilla JS，无引擎）。

## 本地打开

```bash
npx --yes serve -l 4173 /workspace/yedang-mvp
```

手机或浏览器开发者工具 390×844 打开。

## 操作

- **放大镜鉴定**：点虚线圆圈找破绽（线索位有限）
- **收 / 压价**：进入议价，拖动出价或按开口价收下
- **拒 / 报警**：处理可疑客人；误判会掉口碑或升温
- 每晚 6–8 位客人 → 可选翻新 → 打烊结算
- 每周交租、升级工具/店铺、雇人；热度 40/70/100 触发盘问/突查/查封
